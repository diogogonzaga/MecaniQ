#  MecaniQ

O **MecaniQ** é uma plataforma web destinada a pessoas com veículos próprios que precisam de encontrar uma oficina de forma rápida e simples.

##  Problema

Quando um veículo precisa de manutenção ou reparação, pode ser demorado encontrar uma oficina que:

- Tenha disponibilidade;
- Preste o serviço necessário;
- Tenha um preço adequado.

O **MecaniQ** pretende simplificar este processo, permitindo ao utilizador encontrar e comparar oficinas num único lugar.

##  Solução

A plataforma permite ao utilizador:

-  Encontrar mecânicos/oficinas com disponibilidade;
-  Comparar serviços e preços;
-  Marcar um serviço.

##  Público-alvo

Pessoas que possuem veículos próprios e precisam de realizar serviços de manutenção ou reparação.

##  Funcionalidades principais

### 1. Encontrar oficinas

Pesquisar oficinas que realizem o serviço necessário e que tenham disponibilidade.

### 2. Comparar serviços e preços

Consultar diferentes oficinas e comparar os serviços e preços apresentados.

### 3. Marcação de serviço

Escolher uma oficina e efetuar uma marcação para o serviço pretendido.

##  Objetivo

Tornar o processo de encontrar uma oficina **mais rápido, simples e transparente**, evitando que o utilizador tenha de contactar várias oficinas individualmente para descobrir disponibilidade e preços.
